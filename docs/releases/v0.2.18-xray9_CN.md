# Sub2API Xray v0.2.18-xray9 更新说明

发布日期：2026-10-24

本版本同步官方 v0.2.18（0.2.17 → 0.2.18，26 个功能提交），Xray 自身能力全部保留（代理/订阅源管理、用户自有资源工作台、分组模型白名单 scope、用户自有账号上游公网策略等）。

## 官方变更（v0.2.18 摘要）

- 新功能：Vertex 账号支持配额上限（与订阅额度同维度核算，前端账号表单/用量单元格同步适配）。
- 计费修复：Grok 4.7 Fast 按官方 Fast 价卡计费（#8119）；Gemini 流式中途客户端断开时按已收集用量计费；Anthropic 账号兼容流式客户端断开后读完上游再计费；Gemini prompt 被拦截只报缓存命中时 input_tokens 不再为负。
- 网关修复：兼容流上游未正常结束时报错并对齐原生收尾；OpenAI Codex overload 排队/metadata 事件后保留重试与空流安全重试；分组「允许当前分组生图」开关对 Gemini 系入口生效；DeepSeek 生图重复 image payload 修复；tools 参数 constants/annotations 归一化（#8187）；账号列表平台/状态筛选持久化（#8142）。
- 限流修复：Cloudflare 1010 拦截不再计入惩罚；模型限流快照写入改为写时复制。
- 性能优化：调度快照解码结果常驻进程内存；模型映射签名改为与遍历顺序无关、零分配；单 antigravity 账号分组判定改为按需求值；账号配额累加按已设置的周期维度选择语句。
- 安全：异步生图转存下载器重构（目的地公网强制 + 重定向逐跳校验，防 DNS rebinding）；前端依赖 dompurify 升级至 3.4.17（GHSA-cg2g-xh64-v4q7 / GHSA-mrv2-3pqr-j5jr）。
- 构建：Go 工具链升级至 1.27.3。

## Xray 侧适配

- 5 处合并冲突按「Xray 特性 + 官方新功能共存」原则解决：
  - `release.yml`：保留 fork 专用发布 workflow 结构，Go 版本断言跟进官方 go.mod 升级（1.27.2 → 1.27.3）。
  - 三语 README：保留去除赞助商板块的版本，当前版本链接切换到 v0.2.18-xray9。
  - `backend/cmd/server/VERSION`：合并提交对齐官方 tag 值，发布提交升至 0.2.18-xray9。
- 安全一致性检查：官方 v0.2.18 新增的异步生图转存下载链路（`image_storage.go`）自带 socket 级公网目的地强制与重定向逐跳校验（对所有账号生效，比 Xray 的用户自有账号策略更严格），且回调收尾处无账号上下文可绑定代理，故无需再叠加 `ProtectUserOwnedUpstreamRequest`；Xray 既有的全部上游请求公网策略调用点（含同步图片 b64 回填走账号代理下载）经逐一核对均完整保留。
- 验证：后端 `go build ./...` 通过；`go test ./...` 除 `internal/config` 两个用例外全部通过（该两例在官方纯净 v0.2.18 tag 上同样失败，属上游在 Windows 环境的已知问题，非本次合并引入；CI 的 Linux 环境不受影响）。前端 pnpm 9.15.9 冻结安装、i18n 完整性检查、`vue-tsc` 类型检查与 `vite build` 全部通过。
- 本轮官方无数据库 schema 变更，无新增迁移。

## 升级方式

- Docker：`docker pull ghcr.io/caiguanlin/sub2api-xray:0.2.18-xray9`
- Linux 一键安装：`curl -sSL https://raw.githubusercontent.com/caiguanlin/sub2api-xray/main/deploy/install.sh | sudo bash`
- 本版本不含新的数据库迁移，升级前仍建议保留 PostgreSQL、Redis 和应用数据备份。
- 更新完成后请先重启服务，再执行回退操作。
