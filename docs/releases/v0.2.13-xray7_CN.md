# Sub2API Xray v0.2.13-xray7 更新说明

发布日期：2026-10-04

本版本同步官方 v0.2.13（0.2.10 → 0.2.13，共 62 个提交），Xray 自身能力全部保留（代理/订阅源管理、用户自有资源工作台、分组模型白名单 scope 等）。

## 官方新功能（0.2.11 – 0.2.13 摘要）

- Claude 原生额度重置兑换：服务端选择发放窗口，管理端在重置次数旁提供带确认的重置按钮，窗口标签展示更易读（0.2.11）。
- API Key 创建数量与频率限制：可限制单用户创建的 Key 数量与每小时创建次数，默认每小时 60 次（0.2.11）。
- 模型支持 GPT-6.1 Sol；OpenAI 分组支持 Astra Ultrafast 能力与计价（0.2.11）。
- Codex：识别当前订阅计划；客户端配置下发远程模型目录（0.2.11）。
- 充值赠送阶梯：按金额档位额外赠送到账额度；充值优惠阶梯支持折扣模式，快捷金额角标改为促销价签（0.2.12）。
- API Key 列表支持按分组名称排序（0.2.12）。
- Grok：修复 CLI 版本门槛，按官方交互式 CLI 抓包对齐身份头与无界面请求头（0.2.12）。
- TypeSafe 平台多项加固：System One 校验对齐上游 schema、补齐平台迁移与审计覆盖与端点隔离、收紧模型列表口径、错误透传守卫纳入 typesafe；允许 TypeSafe API Key 账号的上游计费探针（0.2.12 – 0.2.13）。
- 计费健壮性：API Key 在计费完成前被删除时仍能正常结算用量（0.2.13）。
- 前端依赖 Axios 升级至 1.20.0，修复安全审计问题（0.2.12）。
- 新增安全策略（SECURITY.md）与私下漏洞上报渠道（0.2.13）。

## Xray 侧适配

- 3 处合并冲突按"Xray 特性 + 官方新功能共存"原则解决：
  - `admin_account.go`：保留 Xray 的代理归属/分组归属校验与混用渠道风险检查，叠加官方新增的 TypeSafe 账号仅允许 API Key 凭据校验。
  - `account_test_service.go`：保留 Xray 的连通性测试 prompt 透传，叠加官方新增的 TypeSafe 账号测试分支。
  - `VERSION`：合并时取官方值，随本 release 提交升至 `0.2.13-xray7`。
- `wire_gen.go` 自动合并正确：`ProvideClaudeResetCreditService`（含幂等与分布式锁接线）与 `idempotencyCoordinator` 前移均已就位，Xray 独有的 `UserResourceService` 接线保留。
- 前端 `auth_source_default_*_platform_quotas` 归一化逻辑随官方纳入 `typesafe` 平台（5 → 6 平台），对应 Xray 测试断言已更新。
- 后端 `go build ./...` 与 `go test ./...`、前端 `vue-tsc` 与 `vitest`（351 个测试文件）全部通过。

## 升级方式

- Docker：`docker pull ghcr.io/caiguanlin/sub2api-xray:0.2.13-xray7`
- Linux 一键安装：`curl -sSL https://raw.githubusercontent.com/caiguanlin/sub2api-xray/main/deploy/install.sh | sudo bash`
- 本版本包含新的数据库迁移。升级前请保留 PostgreSQL、Redis 和应用数据备份，应用启动后会自动执行迁移。
- 更新完成后请先重启服务，再执行回退操作。
