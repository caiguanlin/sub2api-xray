# Sub2API Xray v0.2.10-xray6 更新说明

发布日期：2026-09-30

本版本同步官方 v0.2.10（0.2.4 → 0.2.10，共 608 个提交），Xray 自身能力全部保留（代理/订阅源管理、用户自有资源工作台、分组模型白名单 scope 等）。原 Xray 上游仓库已停止维护，本仓库将继续跟进官方 Wei-Shaw/sub2api 的同步。

## 官方新功能（0.2.5 – 0.2.10 摘要）

- 支持 Claude Sonnet 5.5（含 OpenRouter 计费别名识别）。
- 账号列表支持 Claude 重置额度状态查询与按需刷新，展示重置倒计时。
- OpenCode Go：接入官方用量窗口查询与自动刷新，用量单元格支持主动查询、同 Key 组共享、周/月徽章（7d/1m）。
- 订阅软开关：新增 `subscription_enabled` 与 `payment_balance_disabled`，构成管理端"站点计费模式"选择器，可整体隐藏用户侧订阅入口。
- 风控中心新增用户白名单。
- 仪表盘最近用量支持按 Token / 消费金额切换。
- 分组模型允许清单支持通配符位置匹配；白名单与模型映射冲突检测。
- Claude Code 专用分组可隐藏不支持的客户端入口。
- 大量网关与计费修复：复合模型路由归属校验、WebSocket 上下文滚动衔接、Antigravity 空流故障转移、长上下文计费门槛、客户端断开统一记 499 等。
- 前端 CSV 导出补齐公式注入防护（`=+@-` 前缀转义，`-` 占位符除外）。

## Xray 侧适配

- 全部 25 处合并冲突按"Xray 特性 + 官方新功能共存"原则解决；`subscription_enabled` 与 Xray 的 `enable_user_resources` 同时生效。
- `wire_gen.go` 使用 wire 重新生成，保留 Xray 独有的 db 参数与 UserResourceService 接线。
- 官方新的账号连通性测试调用点补齐 Xray 的 prompt 透传。
- 部署脚本与文档的安装地址、镜像地址全部切换到本仓库（`ghcr.io/caiguanlin/sub2api-xray`）。

## 升级方式

- Docker：`docker pull ghcr.io/caiguanlin/sub2api-xray:0.2.10-xray6`
- Linux 一键安装：`curl -sSL https://raw.githubusercontent.com/caiguanlin/sub2api-xray/main/deploy/install.sh | sudo bash`
- 本版本包含新的数据库迁移。升级前请保留 PostgreSQL、Redis 和应用数据备份，应用启动后会自动执行迁移。
- 更新完成后请先重启服务，再执行回退操作。
