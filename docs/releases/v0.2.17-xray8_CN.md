# Sub2API Xray v0.2.17-xray8 更新说明

发布日期：2026-10-16

本版本同步官方 v0.2.17（0.2.13 → 0.2.17，共 281 个提交），Xray 自身能力全部保留（代理/订阅源管理、用户自有资源工作台、分组模型白名单 scope、用户自有账号上游公网策略等）。

## 官方新功能（0.2.14 – 0.2.17 摘要）

- 安装与支付安全加固：全新安装不再使用可猜测的默认管理员邮箱（未设置时自动生成随机邮箱），AUTO_SETUP 校验管理员密码强度（8–72 字节）与邮箱格式；封堵 EasyPay 支付回调伪造漏洞（return_url 不再保留客户端参数、回调验签拒绝非标准通知参数）（0.2.14）。
- 新增 Cline 平台（ClinePass 订阅额度与积分计费）与 Command Code 平台（按上游模型目录自动分流 Anthropic / Responses / Chat Completions）；平台列表、多协议账号表单与转发/探测逻辑统一改由平台清单驱动，新增平台不再需要数据库约束迁移（0.2.15）。
- 用量页默认展示单请求输出 TPS，运维监控新增输出 TPS 分位数（0.2.15）。
- Claude Haiku 5.5 全链路适配（模型注册、推理强度、定价计费、Responses 桥接）（0.2.16）。
- Gemini 显式上下文缓存：AI Studio / Vertex / 自建网关上游支持创建、续期、删除缓存，内置官方存储价，存储费按 API Key 与订阅额度预留校验（0.2.16）。
- Gemini Vertex（Agent Platform）支持 API Key 认证与服务账号模型列表同步；AI Studio 适配新的 AQ. 格式 Key（0.2.16）。
- 分组名称与描述支持多语言（Accept-Language 本地化）（0.2.16）。
- 临时不可调度规则新增作用范围（暂停整个账号或只冷却当前模型）（0.2.16）。
- Gemini 4 Argon：Antigravity、Gemini API、Gemini CLI 支持 gemini-4-argon（low/medium/high）并补齐计费（0.2.17）。
- Gemini 兼容入口转发 reasoning_effort / thinking 为思考配置，流式返回思考摘要（0.2.17）。
- 新增 `gateway.min_output_tokens`（默认 128，最低 16），作用于各协议转换路径；OpenAI API Key 账号支持 Web Search 模拟（0.2.17）。
- 集中修复支付退款、易支付查单等资金链路问题；Vertex 共享容量 429 改为同号退避重试、服务账号失效自动置错换号（0.2.17）。

## Xray 侧适配

- 19 处合并冲突按"Xray 特性 + 官方新功能共存"原则解决，要点：
  - `subscription_handler.go`：保留 Xray 的订阅池健康度（withPoolHealth），叠加官方新增的分组多语言本地化（Localized）。
  - `antigravity_gateway_service.go` / `account_test_service.go`：官方已原生实现图片模型测试提示词（TestConnectionWithPrompt），按官方结构对齐；Xray 的 prompt 透传保留在 Claude 格式测试请求上。
  - `account_test_service_cn_adaptive.go`：保留 Xray 的测试 prompt 透传参数，叠加官方新增的 providerSupportsProtocol 协议能力判断。
  - `gemini_messages_compat_service.go`：官方将 AI Studio GET 转发重构为 `gemini_models_endpoints.go`（ForwardGetModel / ForwardListModels，支持 Vertex），随官方迁移；Xray 的用户自有账号公网 socket 策略（ProtectUserOwnedUpstreamRequest）已重新应用到新的 doGeminiModelsGET 路径。
  - `CreateAccountModal.vue` / `AccountTableFilters.vue` / `useGeminiOAuth.ts`：合并 Xray 的用户侧 scope、归属筛选与官方的响应式布局、多协议平台清单重构。
  - `release.yml`：保留 fork 专用的发布 workflow；三语 README 保留去除赞助商板块的版本。
- 安全一致性：官方新增的 7 处用户可达上游请求（Gemini 显式缓存、Seedance、OpenAI 图片 b64 回填、TypeSafe/SystemOne/Cline/Command Code 探测等）全部补上 Xray 的用户自有账号上游公网策略。
- ent 生成代码按合并后 schema（Xray owner_user_id + 官方 i18n 等）重新生成；wire_gen.go 与 `wire` 重新生成结果一致（官方 geminiCachedContentService 与 Xray userResourceService 均已接线）。
- 前端 `auth_source_default_*_platform_quotas` 归一化随官方扩展到 13 平台（新增 kimi、zhipu、deepseek、minimax、opencode_go、command_code、cline）。
- 后端 `go build ./...` 与 `go test ./...` 全部通过；前端 `vue-tsc --noEmit` 与 `vitest`（386 个测试文件、2945 个测试）全部通过。

## 升级方式

- Docker：`docker pull ghcr.io/caiguanlin/sub2api-xray:0.2.17-xray8`
- Linux 一键安装：`curl -sSL https://raw.githubusercontent.com/caiguanlin/sub2api-xray/main/deploy/install.sh | sudo bash`
- 本版本包含新的数据库迁移。升级前请保留 PostgreSQL、Redis 和应用数据备份，应用启动后会自动执行迁移。
- 全新安装注意：管理员登录邮箱不再默认 admin@sub2api.local，请从首次启动日志中获取自动生成的邮箱（官方 0.2.14 行为变更）。
- 更新完成后请先重启服务，再执行回退操作。
